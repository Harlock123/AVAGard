# Player guide

## Getting started

1. Choose **Classic** (faithful, about 3.7 seconds per decision) or **Modern** (same rules, gentler).
2. Roll attributes. Constitution is your starting hit points and matters most. Strength, Wisdom and
   Intelligence also help.
3. Name your character. An **empty name gives DEMO**, which has no time limit and cannot be stored.
   It is a good way to learn.
4. You start at the foot of the stairway to the first inn. Stay near the inns until level 2.

## Keys

| Key | Command |
|---|---|
| W / 8 / ↑ | north |
| X / 2 / ↓ | south |
| A / 4 / ← | west |
| D / 6 / → | east |
| S / 5 / Space | stay (a following monster catches up) |
| C / . | cast a spell: level digit, then spell digit (`=` or another key lists them) |
| F1 | store (save) the character |
| F3 | read a Scroll of Rescue |
| F5 | drink a Potion of Healing |
| F7 | drink a Potion of Strength |
| H | help |
| P | replot |
| Q | quit, which kills the character |
| Esc | pause (a modern convenience) |

- **Combat:** F fight, C cast, E evade (F3, F5 and F7 also work, as on the C64).
- **Treasure and offers:** RETURN accepts; any other key declines.
- **Stairs:** U up, D down, S stay.
- **Throne:** P pry, S sit, R read, I ignore.
- **Box:** P push, then R, G, Y and B buttons, or S to stop.
- **Pit:** Y descends; anything else declines.
- **Numbers** (donations, cube levels, teleport offsets): type digits (and `-`), then RETURN.

Every choice also has a clickable button with a tooltip.

## Things worth knowing (from the original rules)

- Gold only becomes experience when you reach an **inn**. Inns are on the surface, up the stairways
  on level 1. Inns also heal you fully, restore spell units and end all effects.
- You rise at most **one level per check**. You need 2,000 experience for level 2, and the amount
  doubles for each level after that.
- A newly found sword, armour, shield, cloak, boots or ring **replaces** the one you carry, even if
  it is worse.
- Evaded monsters **follow** you. Each STAY brings them one step closer.
- Features never wear out: thrones, altars, fountains, boxes and cubes can be tried again.
- Spell levels open at character levels 1, 3, 6, 9, 12 and 15. A spell costs its level in units.
  Spells marked * only work in melee.
- "Never fight a Dragon!" (the manual's advice).
